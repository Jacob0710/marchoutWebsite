# Codex Phase specifications

All Phase execution specifications live directly in this directory.

Naming convention:

- use lowercase `phase<number>.md`;
- do not add spaces, zero-padding, dates, or descriptive suffixes;
- do not place Phase specifications in nested directories;
- continue the existing sequence, for example `phase10.md`, `phase11.md`, and `phase12.md`.

Supporting reports, runbooks, manifests, and generated evidence belong in their existing purpose-specific directories such as `docs/`, `migration/`, and `outputs/` rather than beside the Phase specifications.
